# 🎮 Estudos em C para Desenvolvimento de Jogos

Este repositório marca o início do meu aprendizado em C, linguagem que considero uma base fundamental para o desenvolvimento de software e, especialmente, para o universo dos jogos. Muitas das tecnologias modernas utilizadas em game development possuem raízes diretas no C, seja por meio de engines como a Unreal Engine (C++) ou de bibliotecas amplamente utilizadas como SDL e Raylib. (Em 05/01/2026)

## 🎯 Objetivo

O objetivo deste projeto é construir uma base sólida na linguagem C, com foco inicial em lógica de programação e na compreensão da estrutura da linguagem. A partir dessa base, o estudo evoluirá gradualmente para conceitos mais avançados, como manipulação de memória, entrada de dados e, futuramente, gráficos e interação voltados ao desenvolvimento de jogos.

## 📱 Ambiente de desenvolvimento

Os estudos são realizados no Android utilizando o C4droid para desenvolvimento e geração do APK, e o Termux para versionamento e envio do código ao GitHub.

## 📦 Conteúdo do repositório

O repositório contém exercícios, testes e pequenos projetos em C, além do APK gerado pelo C4droid para download.
