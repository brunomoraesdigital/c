----------------------
📁 NAVEGAÇÃO
----------------------
💻 cd ~/storage/shared/_aqui_meus_git
Entra na pasta _aqui_meus_git dentro do armazenamento compartilhado.

----------------------
⚙️ COMPILAÇÃO EM C (gcc)
----------------------
💻 gcc dinorunc.c -o dinorunc.exe
Compila o arquivo dinorunc.c e gera o executável dinorunc.exe.

💻 gcc dinorunc.c -o dinorunc.exe -Wall
Compila o programa e mostra avisos do compilador sobre possíveis problemas.

----------------------
▶️ EXECUÇÃO DO PROGRAMA
----------------------
💻 ./dinorunc
Executa o programa dinorunc.exe que está na pasta atual.
No Linux/Termux o .exe é apenas parte do nome.

----------------------
📝 EDIÇÃO DE ARQUIVOS (modo texto)
----------------------
💻 nano <nome_do_arquivo>
Abre o arquivo em modo texto para edição.

----------------------
🗑️ REMOÇÃO DE ARQUIVOS
----------------------
💻 rm <nome_do_arquivo>
Remove um arquivo específico.

💻 rm *.exe
Remove todos os arquivos .exe da pasta.

----------------------
🚫 .gitignore (ignorar arquivos)
----------------------
💻 echo "*.apk" > .gitignore
Cria o arquivo .gitignore do zero e escreve a regra para ignorar arquivos .apk.

💻 echo "*.apk" >> .gitignore
Adiciona a regra no final do arquivo .gitignore.

> sobrescreve o arquivo
>> adiciona conteúdo no final

----------------------
✂️ REMOVER A ÚLTIMA LINHA DE UM ARQUIVO
----------------------
💻 sed -i '$d' .gitignore
Remove apenas a última linha do arquivo.

$ = última linha
d = delete

----------------------
👀 VISUALIZAR CONTEÚDO DE ARQUIVOS
----------------------
💻 cat <nome_do_arquivo>
Mostra todo o conteúdo do arquivo no terminal.
