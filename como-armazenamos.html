Como seus dados são armazenados

Entenda de forma simples e transparente como suas informações são protegidas

Seus dados ficam armazenados apenas no seu próprio dispositivo, não sendo enviados para nenhum servidor externo. Isso garante que suas informações estejam sempre sob seu controle.

O que é armazenamento local?

O armazenamento local é uma funcionalidade segura dos navegadores modernos que permite que sites guardem informações diretamente no seu dispositivo - seja computador, tablet ou celular.

É como se o navegador criasse uma "gaveta privada" onde apenas o site que originou os dados pode acessá-los.

Por que isso é seguro?

Privacidade garantida

Seus dados ficam restritos ao seu navegador e dispositivo. Nenhuma outra pessoa, site ou aplicativo pode acessar essas informações.

Sem servidores externos

Suas anotações nunca saem do seu dispositivo. Não são enviadas para a internet nem armazenadas em servidores de terceiros.

Proteção contra vazamentos

Como as informações não transitam pela internet, não há risco de interceptação durante transferências ou ataques a servidores.

Controle total

Você pode limpar os dados a qualquer momento através das configurações do seu navegador, mantendo total controle sobre suas informações.

Perguntas frequentes

Outros sites podem acessar minhas anotações? +

Não. Cada site tem seu próprio espaço isolado no navegador. Os dados do Bloco de Notas só podem ser acessados pelo próprio Bloco de Notas.

O que acontece se eu limpar os dados do navegador? +

Se você limpar os dados do navegador, suas anotações serão removidas. Por isso, se você precisa de backup permanente, recomendamos salvar cópias importantes em outro local.

Meus dados estão criptografados? +

Os navegadores modernos oferecem proteção para dados armazenados localmente. No entanto, para maior segurança em dispositivos compartilhados, recomendamos usar os recursos de proteção por senha do seu sistema operacional.

Posso recuperar meus dados se trocar de dispositivo? +

Como os dados ficam apenas no dispositivo onde foram criados, não é possível acessá-los em outros dispositivos automaticamente. Para isso, você precisaria fazer backup manual das suas anotações.
